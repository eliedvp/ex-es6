# ex-es6

Exercice réalisé pendant la formation GoMyCode : série d'exercices algorithmiques courts résolus en JavaScript moderne (ES6+), regroupés dans `es6.js`.

## Contenu

Chaque solution est précédée d'un commentaire portant le titre de l'exercice (titres de katas de type Codewars), par exemple :

- chaînes : *Vowel Count*, *Disemvowel Trolls*, *Mumbling*, *Stop gninnipS My sdroW!*, *Credit Card Mask* ;
- nombres : *Square Every Digit*, *Descending Order*, *Sum of Digits / Digital Root*, *Find The Parity Outlier* ;
- tableaux : *Sum of positive*, *List Filtering*, *Remove the minimum*, *Counting sheep...* ;
- objets et classes : *FIXME: Get Full Name*, *Regular Ball Super Ball*.

## Notions travaillées

- Fonctions fléchées, paramètres par défaut, template literals
- Déstructuration et opérateur de décomposition (`...`)
- `map`, `filter`, `reduce`, `sort`, `Set`
- Expressions régulières (`match`, `replace`)
- Classes ES6, `switch`, récursivité

## Stack

JavaScript (ES6+).

## Utilisation

`es6.js` regroupe des solutions indépendantes, écrites pour être testées une par une : le fichier n'est pas prévu pour être exécuté d'un bloc. Pour tester une fonction, la copier dans la console du navigateur ou dans Node.js, puis l'appeler, par exemple :

```js
getCount("abracadabra"); // 5
```
